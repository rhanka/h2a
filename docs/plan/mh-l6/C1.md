# C1 — lanceur autonome et diagnostic conservateur

Le build produit un seul fichier ESM qui n'importe que des modules Node intégrés.
Il dérive l'installation de son emplacement physique sous `I/launcher/h2a.mjs`,
revérifie le préfixe et la sélection, puis importe l'entrée absolue de l'image
dans son propre PID. Il neutralise `NODE_PATH` et refuse les options de chargement
hors profil, y compris celles de l'argv Node. Les seuls flags optionnels admis ici
sont les plafonds mémoire `--max-old-space-size=…`.

`upgrade status` est un diagnostic autonome en lecture seule. Si la sélection
est illisible, la dernière sélection vérifiée et l'historique peuvent fournir
un candidat de récupération ; aucun code de repli n'est exécuté et aucun droit
de mutation n'en découle. Un journal inconnu refuse un diagnostic fiable.
Une intention `SELECTING` interdit l'import normal avant réconciliation.
La divergence du lien npm et le masquage PATH sont visibles sans réécriture.

Le rouge initial constate six comportements sans lanceur. Le rouge de profil
montre un import réel de la petite image de test malgré un runtime sans preuve
glibc ; la garde est maintenant exécutée avant cet import et sa mutation est
tuée. Le lancement par sous-processus, les chargements externes, les pertes de
vérification, les replis exécutables et les gardes de lien/journal ont chacun
une mutation comportementale.

`scripts/mh-l6-c1-audit.mjs` vérifie 12 fichiers du graphe/source/tests/runners,
les reçus des deux profils, la restauration et l'égalité des bundles produits
depuis le worktree et la copie privée. L'artefact concret et son manifeste sont
dans [artifacts](artifacts/launcher-manifest.json), digest
`sha256:4b4b578765f081869d40bfaefae1ba9830d84731f1133b2bd287105959f155c0`.
L'outil esbuild est utilisé au build uniquement, avec les versions déjà résolues
par le lock du dépôt ; l'utilisateur du lanceur n'en dépend pas. Les services
de build créés par l'audit sont explicitement arrêtés.

La compilation ciblée `node node_modules/typescript/bin/tsc -b packages/h2a
--pretty false` retourne 0 sans diagnostic (`evidence/build-C1.log`).
Les reçus A et B1 restent respectivement ceux de `dd23a00a` et `ff65a2be` ;
leurs sources produit sont inchangées par C1. Le runner de mutations reçoit
uniquement le groupe supplémentaire `launcher`.
