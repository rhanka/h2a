## Two detail choices

1. **Pre-pass reclaim + per-round reclaim test:** correct
   direction, partially overstated. `snap0` before `mint()`
   avoids minting when reclaim was already possible at entry,
   and the loop-head test avoids a stale mint winning.
   But `mint()` + `beforePublish` still run before the first
   loop-head test, so a binding appearing in that window still
   orphans one keypair/alias row. To fully meet the stated
   intent, move `beforePublish` inside the loop after the
   reclaim test, re-entrant on the same `mintResult`.
   Growth only, not a safety issue.

2. **`now === line` → `unlinkOwnSlot` before return:** correct.
   The line is already durable and visible via roll-forward
   elsewhere; token-checked unlink with `ENOENT` ignored cannot
   delete a successor slot. Approve as written.
