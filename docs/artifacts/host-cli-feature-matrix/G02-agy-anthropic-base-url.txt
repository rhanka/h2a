  Here are the standard approaches and tools for running or implementing a **Gateway Probe**:

  ---

  ### 1. Quick CLI Network Gateway Probe (Linux / macOS)

  Run these commands to find and test your active default gateway:

  ```bash
  # 1. Identify the default gateway IP and interface
  ip route show default
  # Or on macOS/BSD:
  # route -n get default | grep gateway

  # 2. Extract gateway IP and probe reachability (5 packets)
  GATEWAY_IP=$(ip route show default | awk '{print $3}')
  echo "Probing default gateway: $GATEWAY_IP"
  ping -c 5 "$GATEWAY_IP"

  # 3. Check ARP / Neighbor table entry for MAC resolution
  ip neigh show "$GATEWAY_IP"

  # 4. Check MTU and Path MTU Discovery
  tracepath "$GATEWAY_IP"
  ```

  ---

  ### 2. Standalone Gateway Probe Script (Bash)

  A script to continuously or periodically probe gateway health, latency, and packet loss:

  ```bash
  #!/usr/bin/env bash
  set -euo pipefail

  # Auto-detect default gateway
  GW=$(ip route show default 2>/dev/null | awk '/default/ {print $3}' | head -n 1)

  if [[ -z "${GW:-}" ]]; then
    echo "[ERROR] No default gateway found."
    exit 1
  fi

  echo "=== Probing Gateway: $GW ==="

  # Ping gateway
  if ping_output=$(ping -c 4 -W 2 "$GW" 2>&1); then
    rtt=$(echo "$ping_output" | awk -F'/' 'END {print $5}')
    loss=$(echo "$ping_output" | grep -oP '\d+(?=% packet loss)')
    echo "[OK] Gateway is reachable."
    echo "     Packet Loss: ${loss}%"
    echo "     Average Latency: ${rtt} ms"
  else
    echo "[FAIL] Gateway $GW is unreachable!"
    exit 2
  fi
  ```

  ### 3. API / Kubernetes Gateway Health Probe

  If you are configuring liveness/readiness probes for an API Gateway or Ingress controller (e.g., Envoy, Kong, NGINX, Traefik, Istio):

  ```yaml
  livenessProbe:
    httpGet:
      path: /healthz      # or /status, /ready
      port: 15021         # e.g., Istio healthcheck port or gateway status port
      scheme: HTTP
    initialDelaySeconds: 5
    periodSeconds: 10
    timeoutSeconds: 3
    failureThreshold: 3
  readinessProbe:
    httpGet:
      path: /ready
      port: 15021
    initialDelaySeconds: 2
    periodSeconds: 5
    timeoutSeconds: 2
    failureThreshold: 2
  ```
