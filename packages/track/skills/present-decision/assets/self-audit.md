# Dossier self-audit

Missing evidence, criteria or review: **Incomplete**; request input, never final validation.

- [ ] **Title first:** subject and decision object in plain words; distinguishable among 50 dossiers;
  one short line, no slogan/thesis. HTML `<title>` matches the visible title;
  small type (≤1.25rem), thin band, no hero.
- [ ] **Owner interest:** owner benefit/risk and intention; no agent inconvenience or false problems.
- [ ] **Reading budget:** fits the stakes; question, context, 2–4 short options and
  recommendation: 2 minutes, at most 400 words.
- [ ] **Self-contained:** representative scenario, current behavior, affected people and constraints
  clear without links. Plain words; no opaque codes; acronyms explained.
- [ ] **No hidden decisions:** every implied choice explicit; no nested sub-options.
  Questions stand alone; dependencies stated. Supporting evidence hides no choice or material risk.
- [ ] **Traceability:** dated/sourced literal owner request quoted; demands map to
  questions/options/criteria. Departures explicit; each criterion covered or the decision asked.
- [ ] **Options and recommendation:** one-line owner consequence, cost/rollback and strongest honest case per option.
  Recommendation, strongest objection and overturning condition stated.
- [ ] **Evidence and bias:** decisive claims: `[FACT]` with sources or `[JUDGMENT]`;
  assumptions/unknowns separate; failure scenario; presenter convenience separate from owner value.
- [ ] **Reviews:** independent Codex + Opus passes for complex design; disagreements surfaced.
- [ ] **Delivery/capture:** default `h2a focus build dossier.json -o dossier.html`; portable Focus HTML,
  ecosystem canvas, light/dark, phone pinch zoom; no claude.ai artifact. Dossier with diagram before the native question tool;
  never a bare text question. If unavailable, explain and leave the decision pending.
  Local selections; no fabricated `comprehension[]` or relay as decider.
- [ ] **Evidence (H1):** original bytes/digests; resolved citations/backlinks; primary summaries,
  separate annex consultation; offline search/download/back. H1 manifest only;
  DS in-canvas controls await H2/H3.
